# Plague House

**London, 1665. One street. One summer.**

> **[Play Plague House live](https://thehillbeyondthisone.github.io/plague_house/)**

A browser-first historical simulation about responsibility under uncertainty. You are a parish examiner assigned to Bell Lane. Walk the street, learn its households, inspect what you can actually observe, keep a ledger, make limited interventions, and live with what happens after dark.

## Prototype
The first vertical slice is intentionally small: eight persistent households, a hidden epidemic simulation, imperfect testimony, limited daily actions, quarantine decisions, a living street, and a diegetic parish ledger.

The game is a zero-build static site and deploys to GitHub Pages from `main`.

**Design rule:** the simulation knows the truth. The player knows only evidence.
